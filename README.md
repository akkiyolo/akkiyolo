## 👑 **About the Sovereign**

A final-year Computer Science undergraduate, currently forging the architecture of tomorrow's intelligent systems. Doom's gaze has turned toward the role of **Forward Deployed AI Engineer** — deploying autonomous agents into production, where mere mortals tremble.

**Current Domains of Conquest:**
- 🧠 **Agentic AI Systems** — LangGraph orchestrations, multi-agent pipelines, LLM-as-judge frameworks
- ⚙️ **MLOps** — End-to-end pipelines from notebook to productionized inference
- 🏗️ **Full-Stack Backend** — Async FastAPI services, PostgreSQL, containerized deployments
- ☁️ **Cloud Infrastructure** — AWS (ECR, EC2, S3), CI/CD via GitHub Actions

*Latveria does not ask "what stack?" Latveria asks "what dominion?"*

### 🏰 **Dominion I — The Citadel of Agentic Blogging**

**Repo:** [Agentic-Blog-App](https://github.com/akkiyolo/Agentic-Blog-App)
